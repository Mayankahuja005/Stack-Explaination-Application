# 📚 Stack Master – Interactive DSA Learning App

An interactive web application designed to make learning **Stack Data Structure** simple, visual, and engaging.

## 💡 About the Project

As the **SoftTech Head at BVPISTE**, I conducted a DSA learning session for my college juniors.

My assigned topic was **Stack Data Structure**.

To make the concepts easier to understand, I developed this interactive web application to help students visualize stack operations, understand the LIFO principle, and practice stack-based problems.

The goal was to make DSA learning more interactive rather than relying only on theoretical explanations.

## 🚀 Features

### 1. Learn Mode
- Interactive visualization of Stack.
- Understand the LIFO (Last In, First Out) principle.
- Perform Push, Pop, Peek and isEmpty operations.
- Understand Stack Overflow and Stack Underflow.

### 2. Mission Mode
- Interactive stack-based challenges.
- Predict the results of stack operations.
- Multiple difficulty levels.
- Score-based learning.

### 3. Quiz Mode
- Practice stack-based questions.
- Predict the top element after Push and Pop operations.
- Instant feedback.
- Score tracking.

## 🛠️ Tech Stack

## 🎯 Learning Objectives

- Understand Stack Data Structure.
- Learn the LIFO principle.
